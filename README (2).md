
# Expense Tracker App

A clean, responsive, and user friendly **Expense Tracker** built with **HTML, CSS, and JavaScript**.  
This app helps users manage their finances by tracking income, expenses, and transaction history — all stored locally in the browser.


##  Features

- **Add Income & Expenses** with descriptions and amounts  
- **Automatic Balance Calculation** (Income - Expenses)  
- **Transaction History List** with color coded entries  
- **Delete Transactions** instantly  
- **LocalStorage Support** so data stays after refresh  
- **Responsive UI** for mobile and desktop  
- **Modern, clean design** with smooth layout
